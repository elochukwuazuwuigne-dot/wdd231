Lagos Tech Hub Site Plan

Site Name

Lagos Tech Hub

This name was selected because it clearly represents a technology hub located in Lagos, Nigeria. It is professional, memorable, and directly communicates the purpose of the organization.

Site Purpose

The Lagos Tech Hub website will provide information about technology training programs, coding bootcamps, workshops, networking events, and membership opportunities. Visitors will be able to learn about available resources, upcoming events, and ways to participate in the local technology community.

Scenarios

  • What coding programs and workshops are available for beginners?
  • How can I register for upcoming technology events?
  • What benefits do members receive?
  • How can I contact Lagos Tech Hub for partnership opportunities?

Color Schema

Primary Color: #0A66C2

Used for headings, navigation, buttons, and important highlights.

Secondary Color: #F4F4F4

Used for page backgrounds and content sections.

Accent Color: #222222

Used for body text, footer content, and general text.

Typography

Poppins

Poppins will be used for headings, navigation links, and other prominent text elements.

Arial

Arial will be used for body text, forms, and general content.
